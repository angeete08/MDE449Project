# Two-minute demo

1. Open Stride. Select gain muscle, beginner, three days, bodyweight and vegetarian. Enter a chosen daily calorie target and create the week.
2. Show seven days, exactly three workouts, rest days, sets/reps, and the calorie target.
3. Show vegetarian meal ideas and approximate portion calories; explain that these are not a complete daily meal plan.
4. Log Monday as too hard. Show that Monday stays unchanged while Wednesday and Friday have one fewer repetition per set.
5. Refresh. Confirm the profile, plan and Monday feedback remain.
6. Download the JSON plan. Change equipment to dumbbells and generate again; show the new exercise choices and cleared feedback.

Feedback to collect next: Can a teammate create a plan without assistance? Do they understand rest days and meal estimates? Is the feedback effect clear?

Run `jac install`, then `jac run` from the repository root. Open http://localhost:8000. Explain that all authored application code is Jac and that the planning is deterministic; live model integration remains future work.
